# Telecom Customer Churn Prediction

Predicting which telecom customers are likely to cancel their subscription using machine learning.

## Overview
Built a binary classification pipeline on 7,000+ telecom subscribers to identify customers at risk of churning, enabling proactive retention strategies.

## Key Results
- **Accuracy: 82%** | **AUC-ROC: 0.87**
- **Top churn drivers:** Contract type, tenure, monthly charges
- Applied **SMOTE** to handle class imbalance

## Tech Stack
Python · Pandas · Scikit-Learn · XGBoost · Matplotlib

## How to Run
1. Clone the repo
2. Install requirements: `pip install pandas scikit-learn xgboost matplotlib imbalanced-learn`
3. Open the notebook in Jupyter or Google Colab
